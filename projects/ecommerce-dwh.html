Data Warehousing 2025

E-commerce Data Warehouse

Modernizing data infrastructure with Snowflake and dbt.

The Challenge

The business was struggling with siloed data across Marketing (Facebook Ads), Sales (Shopify), and Inventory systems. Reports were manually generated in Excel, leading to inconsistencies and stale data.

The Solution

We built a centralized Enterprise Data Warehouse (EDW) in Snowflake. We used Fivetran for EL (Extract-Load) and dbt (data build tool) for T (Transformation).

  • Schema Design: Implemented a Kimball Star Schema with Fact tables for Orders and Inventory, and Dimension tables for Customers, Products, and Time.
  • Modeling: Used dbt to handle data testing, documentation, and lineage.
  • Performance: Optimized queries using Snowflake's clustering keys and materialized views.

Key Implementation Details

The dbt project structure ensures modularity. We implemented incremental models to process only new data, significantly reducing warehouse costs.

-- models/marts/core/fct_orders.sql
{{ config(
    materialized='incremental',
    unique_key='order_id'
) }}

WITH orders AS (
    SELECT * FROM {{ ref('stg_shopify_orders') }}
),

payment_rollup AS (
    SELECT * FROM {{ ref('int_payment_rollup') }}
)

SELECT
    o.order_id,
    o.customer_id,
    o.order_date,
    p.total_amount,
    p.payment_status
FROM orders o
LEFT JOIN payment_rollup p ON o.order_id = p.order_id

{% if is_incremental() %}
    WHERE o.updated_at >= (SELECT MAX(updated_at) FROM {{ this }})
{% endif %}
