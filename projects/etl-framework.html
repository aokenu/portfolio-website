Automated ETL Framework

Orchestrating complex data dependencies with Apache Airflow and Docker.

The Challenge

The client's data engineering team was spending 40% of their time manually triggering scripts and debugging cron job failures. There was no visibility into job status or dependencies.

The Solution

I developed a robust ETL framework using Apache Airflow deployed on Docker/Kubernetes. This allowed for:

  • Dynamic DAG Generation: Python scripts that automatically generate DAGs based on configuration files (YAML).
  • Containerized Tasks: Each task runs in an isolated Docker container, preventing dependency conflicts.
  • Alerting: Integrated Slack notifications for job failures and retries.

Key Implementation Details

Self-healing pipelines were a priority. We used Airflow sensors to wait for external data availability before triggering downstream tasks.

# dag_generator.py
from airflow import DAG
from airflow.operators.python_operator import PythonOperator
from datetime import datetime

def create_dag(dag_id, schedule, task_config):
    dag = DAG(dag_id=dag_id, schedule_interval=schedule, start_date=datetime(2023, 1, 1))
    
    with dag:
        previous_task = None
        for task_name in task_config['tasks']:
            task = PythonOperator(
                task_id=task_name,
                python_callable=run_etl_step,
                op_kwargs={'step': task_name}
            )
            if previous_task:
                previous_task >> task
            previous_task = task
            
    return dag

# Dynamically generate DAGs from config files
for config in load_configs():
    globals()[config['id']] = create_dag(config['id'], config['schedule'], config)
